# SocialHub - Simple Social Media Platform

A clean, modern, and fully functional **simple social media platform** built with pure HTML, CSS, and JavaScript.

Perfect for students to learn and later upgrade for real-world use (developers, businesses, communities).

## Features

- User Registration & Login
- Create Posts (text + optional image URL)
- Like & Comment on posts
- Follow / Unfollow users
- Profile page with stats
- Edit Profile (name, bio, avatar)
- Dark / Light mode
- Fully Responsive
- Data stored in browser (localStorage)

## How to Run Locally

1. Download or clone this repository
2. Open `index.html` in any modern browser
3. That's it! No server needed.

## Deploy on GitHub Pages

1. Go to your repository **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` → `/ (root)`
4. Click Save
5. Your live site will be available at:  
   `https://missionbist100.github.io/simple-social-media/`
